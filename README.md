## Sobre o Projeto
Este projeto consiste em desenvolver uma landing page para psicólogos, como parte da segunda tarefa do processo seletivo da Linked(Empresa Júnior).

A página foi desenvolvida com base no layout disponibilizado pela empresa através do Figma, onde há de buscar fidelidade visual, responsividade, acessibilidade básica e organização do código.

## Tecnologias Utilizadas
- HTML5 - Estrutura e semântica da página
- CSS3 - Estilização e responsividade da página
- JavaScript(Vanilla) - Elementos decorativos e interações implementadas no projeto

## Como Executar
1- Clone este repositório ou baixe os arquivos.  
2- Abra a pasta do projeto no Visual Studio Code ou em outro editor.  
3- Abra o arquivo index.html diretamente pelo navegador.  

Obs: Não é necessário instalar dependências como npm para executar a versão do HTML, CSS, JavaScript.

## Decisões Técnicas
- Utilização de HTML, CSS e JavaScript puro, conforme as tecnologias permitidas no desafio.
- Organização de estilos para adaptar a página a diferentes tamanhos de tela.
- Uso de elementos decorativos com JavaScript, quando aplicável.
